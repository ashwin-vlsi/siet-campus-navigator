# SIET Campus Navigator

A GitHub Pages student project for finding SIET exam halls/classrooms and their verified block/floor locations.

## Data source
The `rooms.json` database is transcribed from the SIET **EXAM HALL LOCATION** sheet supplied for this project.

It includes LH 01-06, 07-12, 13-16, 17-23, LH 24-28, the listed LH 30 and LH 32-55 rooms, MELH 09/10/12-14, Seminar Hall-II, Lab 08/14/15, and the Tech Park New Block 1A/1B/1C and 2A/2B/2C groups.

## Important
The supplied sheet gives block/floor/location information. It does not provide exact corridor/staircase paths or a measured floor plan, so the navigator does not invent those details. Exact turn-by-turn routes can be added later using verified campus-map data.
